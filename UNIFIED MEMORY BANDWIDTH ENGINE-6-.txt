CPU load (with history)

RAM free ratio

Disk latency

Pressure metrics:

This feeds directly into tier decisions and tuner behavior.

📡 4. Bandwidth Auto‑Tuner (PID + Heuristics)
This is one of the most advanced parts.

Inputs
CPU load

RAM free ratio

Disk latency

Workload type (file / network / sensor / mixed)

Real bandwidth (RAM / disk / swarm)

Outputs
target_cache_percent (5%–80%)

Behavior
PID loop tries to maintain 35% free RAM.

Penalizes high CPU or disk latency.

Boosts cache for file workloads, reduces for network workloads.

Adjusts based on which tier is fastest.

This tuner continuously calls back into the engine to resize RAM cache.
